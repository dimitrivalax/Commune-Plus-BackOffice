# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do **not** open a public GitHub issue for security problems.

- Email: [contact@commune-plus.fr](mailto:contact@commune-plus.fr)
- Or use [GitHub Security Advisories](https://github.com/dimitrivalax/Commune-Plus-BackOffice/security/advisories) on this repository if enabled

Include steps to reproduce, affected versions, and impact when possible.

We aim to acknowledge reports within a few business days.

## Scope

- Application source code in this repository
- Default configurations and documented deployment paths

Out of scope: third-party services you configure yourself (Firebase, Cloudinary, Resend, PostHog, Meta, etc.), and production instances you do not operate.
